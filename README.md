# Magnifier

A simple magnifier for PDFs and pictures that works in any phone or computer browser.

**Open it:** https://svarki79-wq.github.io/magnifier/

- Tap **Open PDF or image** and pick a file. It stays on your device; nothing is uploaded.
- Pinch or scroll to zoom, drag to move, double-tap to zoom in.
- **Lens** shows a magnifying glass you can drag around.
- **Fit** shows the whole page, **Width** fills the screen with the page width.
- PDFs with several pages get page arrows at the top.

## Open a file straight from the link

Put a PDF or picture in this repository, then add `?file=` and its name to the link:

- `https://svarki79-wq.github.io/magnifier/?file=family-tree.pdf`
- `https://svarki79-wq.github.io/magnifier/?file=family-tree.pdf&page=2` (start on page 2)

Note: anything stored in this public repository can be seen by anyone who finds it.

Everything is in one file, `index.html`, including the PDF reader ([PDF.js](https://mozilla.github.io/pdf.js/), Apache 2.0).
